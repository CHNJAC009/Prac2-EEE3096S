\section{Fault Diagnosis}
\label{sec:fault}

The fault case (\reg{RUN\_TASK}~$=5$) runs the Task~4 program with one
configuration setting changed; \reg{RUN\_TASK}~$=4$ runs the identical program
without it. The same measurement was captured in both modes
(\cref{fig:fault}).

\begin{enumerate}
  \item \textbf{Expected.} \fillin{waveform / behaviour expected from the EEPROM protocol}
  \item \textbf{Measured.} \fillin{what the board actually produced (LEDs, status/read values, scope)}
  \item \textbf{First meaningful difference.} \fillin{the earliest point at which faulty and correct traces differ}
  \item \textbf{Responsible register and field.} \fillin{register, field, faulty value}
  \item \textbf{Correction.} \fillin{corrected field value}
  \item \textbf{Repeated measurement.} \fillin{result after correction and why it now meets the requirement}
\end{enumerate}
