\paragraph{Why \texttt{volatile}.}
A peripheral register can change, or react to being accessed, independently of
the program flow. \texttt{volatile} forces the compiler to perform every read and
write exactly as written instead of caching the value or removing accesses it
considers redundant; without it, the read of ODR could be cached and the
BSRR/BRR writes optimised away.
